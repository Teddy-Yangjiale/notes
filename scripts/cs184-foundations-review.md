## 以薄弱处为单位补充

每篇新增 3 个深入专题，共 24 个。每个专题写明输入和约定、课件回查页、分步推导、几何或数值图、手算、独立回查、适用边界、可运行 Python 代码及实际输出、实现诊断和一道带推理答案的自测。补充实验是明确假设下的教学模型，不是课件实测或完整渲染器的性能测试。

| 篇章 | 本轮三个深入专题 |
|---|---|
| 02 | 共享边怎样做到恰好归属一个三角形；包围盒的整数范围与分块极值怎样推出来；覆盖率档位为什么不是二维采样误差上界 |
| 03 | 同一组样本为什么无法判断原来是哪条波；把 box 与 tent 的频率响应算到同一单位；随机、相关与有偏：三种误差不能套同一条收敛律 |
| 04 | 相机位姿求逆：为什么是先减位置再转回基底；为什么裁剪要在透视除法之前完成；局部深度精度必须求导，不能平均分配远处范围 |
| 06 | UV 导数先换 texel 单位，再看足迹主轴；透视插值的导数：LOD 也必须跟着分母变化；半 texel 偏移与纹理图集串色怎样从权重看出来 |
| 08 | 为什么深度能屏幕线性插值，普通属性却不能；先插值法线再归一化，为什么不同于插值亮度；PCF 要先比较再平均，阴影偏置则要看深度斜率 |
| 10 | C1 与 C2 拼接必须包含时间区间尺度；自适应细分的误差要量到线段，而不只是直线；有理 Bézier 怎样精确表示四分之一圆 |
| 11 | 翻边后的 Euler 数正确，为什么半边仍可能坏掉；QEM 奇异时如何把最优点限制在线段上；Loop 更新为什么必须读旧位置、写新位置 |
| 13 | Möller–Trumbore 的符号怎样用回代锁定；AABB 相切、平行与有限线段要放进同一个区间；SAH 怎样比较切分与不切分，而不丢单位 |

## 原文实质纠错

- L02：区分斜边中点与重心；按像素中心重算候选盒；纠正右侧覆盖率、针形例子、块分类与逐点测试混算；删除通用灰度误差界和无依据硬件加速倍数；同步修正旧自测题干及答案。
- L03：纠正 Nyquist 频率、滤波器响应数值和采样误差叙述；给出二维反例，区分覆盖率量化、偏差与随机方差。
- L04–05：明确正距离 s=−z_eye，纠正常规定点深度范围占比及远处局部量化间隔；避免把负观察坐标与缓冲编码混用。
- L06–07：补齐 texel/pixel 单位；纠正三线性插值层数、透视误差阈值和棋盘频率；区分模型采样次数与硬件访存次数。
- L08–09：修正深度编码、early-Z 条件、着色工作量和附录答案错配；区分点光源辐照度的距离衰减与辐亮度传播；整理原自测编号并删除重复题。
- L10：补全线性再现、次数退化例外、二阶参数导数条件和有限弦段误差；修正导数方向的归一化数值。
- L11–12：解完非对角 QEM 方程并回代；修正 Catmull–Clark 边数、收缩条件和奇异矩阵判断；删除无实测依据的运行时间。
- L13：统一 Möller–Trumbore 方程符号；区分 u/v 互换对包含性与属性插值的影响；明确 AABB 闭区间；恢复 SAH 父面积与图元测试代价后再比较叶子。

移除 8 篇末尾未完成的“待生成图 / 提示词占位”。旧正文与新练习中的相关结论、图注、速查表、自测题干和已有答案同步核对；不把新增专题当作与旧文矛盾的孤立补丁。
