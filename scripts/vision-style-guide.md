# 视觉大模型专栏 · 写作模板（STA-5007 式"论文逐图精讲"）

> 2026-10-19 起生效。第 12 讲（ViT）是按本模板写的样板；第 25 讲起全部按本模板写，已写的 01—24 讲逐篇改写。
> 校验脚本 `scripts/vision-verify.mjs` 只检查公式、链接、图片和可运行代码，不检查风格，所以风格靠本文件约束。

## 一、旧稿为什么"不易懂"：审稿结论

对 01—24 讲（约 134 万字）和 STA-5007 四讲（约 68 万字）做了对照统计：

| 指标 | 旧视觉稿 | STA-5007 |
| --- | ---: | ---: |
| "不能 / 不等于 / 不保证 / 不意味着 / 不是" 每万字出现次数 | 14 | 3 |
| `🖼 逐元素图解`（讲清图里每个方块和箭头） | 29 处 / 25 篇 | 160 处 / 4 篇 |
| `💡` 直觉框 / `⚠️` 易错框 | 0 | 75 / 58 |
| 带 `<details>` 折叠解析的练习 | 0 | 148 |
| 原始材料截图（课件页 / 论文图表） | 0 | 每页一张 |

具体症状：

1. **是事实清单，不是一堂课。** 一讲被切成 45—60 个等权重的 `### 12. xxx` 小节，没有"这一讲在和谁争论、要证明什么"的主线。
2. **讲的是"知识"，不是"论文"。** 读者看不到论文自己的图和表，只能看作者转述的结论；STA-5007 每一页都先放原始课件截图，读者看到的是一手材料。
3. **先定义，不给动机。** 小节第一句就是"设 P=…"，而不是"上一步留下了什么问题"。
4. **每段都在纠错。** 大量"X 不是 Y、不能把 A 当 B"的否定句；初学者还没形成这些误解，读起来像一堵墙。
5. **图没有图解，练习没有过程。** SVG 下只有一行标题；练习答案一行带过，没有推理，也不折叠。
6. **排版细节。** 中英文和数字之间不加空格；第 14—23 讲删掉了全部三级标题，目录没法导航。

第一次改写（2026-10-19 上午）保留了"自编讲义"的形式，只加了框和练习，用户反馈仍然"太僵硬"。**根源是没有像 STA-5007 那样以原始材料为中心**：STA-5007 是"课件页 → 原文要点 → 图解 → 机制 → 易错点"，视觉专栏对应的原始材料就是**论文的图和表**。

模块开场白：这几页在回答什么问题，答案是怎么逼出来的。

#### 图 N　短标题                   ← 一张论文图/表/公式/关键段落 = 一个 #### 条目

![图 N · 说明](./images/paper-figN-xxx.png)
**🖼 逐元素图解**                   ← 表格或列表：每个方块、曲线、坐标轴、列名各是什么；读图顺序

> **💡 为什么这样设计 / 直觉**
> **⚠️ 易错点**（一框一个，说清错在哪一步）

## 附录 A · 核心概念速查            ← 表：概念 / 一句话 / 出处（图 N、表 N、第几节）

## 三、论文图表怎么截

1. 把论文 PDF 下载到会话的临时目录（不要放进仓库）：`curl -sL https://arxiv.org/pdf/<id> -o <dir>/<name>.pdf`。
2. 渲染成页图：`swiftc -O scripts/render_pdf_pages.swift -o <dir>/render && <dir>/render <pdf> <dir>/pages 2000`（只依赖 macOS 自带框架）。
3. 看缩略图定位图表，再用 PIL 按坐标裁剪，裁剪宽度不超过 1400px，存为 `images/paper-figN-<slug>.png`、`paper-tableN-<slug>.png`、`paper-eqN-M.png`、`paper-p1-abstract.png`。
4. 选图原则：**模型总览图、核心公式、配置表、主结果表、主要曲线图、消融表、模型诊断图**都要；不截参考文献和纯文字页（关键段落直接引英文原句）。
5. 每张截图下第一行是原文 caption（斜体），讲解里引用论文原句时也用斜体英文 + 翻译。
6. 原始材料一节声明：截图来自论文 arXiv 版，版权归原作者，讲解为笔记作者补充。

## 四、段落写法

- **面向零基础、顺着专栏学下来的读者。** 一个术语第一次出现给中英文和一句话定义（预训练、微调、Top-1、few-shot linear、exaFLOPs……），并链接到前面讲过它的那一讲。
- **先问题，后机制。** 每个条目开头一句话说清它回答什么问题。
- **一个公式三件事。** 逐符号对照到论文的图里去；标维度；给一个两三行能算完的"跟着算"。
- **结论句加粗，放段首。**
- **否定句收进 ⚠️ 框。** 正文讲正确机制；易错点集中成一框，说清"错在哪一步、怎么发现"。
- **💡 框讲"为什么这样设计"**，以及和前后讲、前后图的联系。
- **表格代替排比句**；形状链、序列布局用等宽代码块。
- **中英文、数字之间加空格**："ViT-B/16 有 196 个 patch""τ = 0.5 时"。
- **教学数字的免责声明只在原始材料一节写一次。**

## 五、算例、练习与核查

- "跟着算"紧跟它要说明的图或公式；大型算例（账本、完整反传）可单独成 `#### 跟着算　标题`。
- 练习每模块 4—8 题，★ 标常考，`<details>` 折叠，先思路后数字，最后一句说"这题考什么"。
- 保留 `~~~python` 块并说明核对范围；写完跑 `node scripts/vision-verify.mjs --source-only`，再 `npm run build` 后跑完整校验。

## 六、篇幅与密度

- 篇幅由论文决定：论文有几张关键图表就有几个 `####` 条目；二级标题 5—8 个；目录只显示二级和三级（练习）标题，`####` 条目不进目录，和 STA-5007 一致。
- 每个 `####` 条目 3—10 段；超过就拆。

## 七、改写旧稿的步骤

1. 下载该讲涉及的论文，按第三节截图。
2. 以论文页码为主线重排模块；旧稿的 45—60 个小节变成图表条目下的段落。
3. 旧稿每一句"不能 / 不等于"：要么删，要么并进本条目的一个 ⚠️ 框。
4. 本站已有的 SVG 保留给"跟着算"条目，每张补 🖼 图解；没用上的删掉（连同 `scripts/vision-diagrams.mjs` 里的生成代码）。
5. 旧练习按模块分组，补推理过程，改成 `<details>`；补 📌 位置框和附录 A/B/C。
6. 跑校验，构建，浏览器里看一遍再提交。
