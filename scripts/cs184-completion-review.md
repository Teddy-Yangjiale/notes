## 来源和解释范围

秋季课件提供导论、辐射度量、蒙特卡洛和全局光照；春季补材质、颜色、动画、物理、流体与 VR；夏季补相机透镜与图像处理。正文保留学期、文件名、从 1 开始的 PDF 页码、全页索引、原文件链接和 SHA-256。全页索引不表示逐页均有独立讲解，静态 PDF 不能复现原视频运动。

重点核对了以下条件，避免公式脱离适用范围：

- 面积到立体角的 Jacobian、Lambertian 半球积分的 π、圆盘近场与远场的区别。
- PDF 的测度和支持集、估计量期望与方差、俄罗斯轮盘权重、MIS 重复计数、有限反弹截断偏差。
- Snell 切向分量和全反射、精确 Fresnel 与 Schlick、投影面积 NDF、Beer–Lambert；同色异谱、sRGB 分段和线性空间预乘 alpha。
- Hermite 速度的时间单位、四元数双覆盖、绑定矩阵逆变换、IK Jacobian 的有限差分；不同 Euler 格式的能量行为及不同质量的约束修正。
- 压力梯度与压力 Laplacian 的类型差异、离散 D/G 与边界一致性、Poisson 残差对应剩余散度、平流有界与保细节/守恒的区别。
- 立体视差误差、平移重投影对深度的需要、刷新周期与全链延迟；固定机位焦距变化与移动机位透视变化、散焦和景深、光子数与增益的信噪比区别。
- 卷积边界、Sobel 可分离结构、双边滤波逐像素归一化与非线性、2×2 DCT 量化重建误差。

材质与颜色的扩展资料在对应段落直接链接 PBRT 第四版和 W3C CSS Color 4。其他补充计算由明示假设独立展开。

npm ci

powershell -File scripts/cs184-render-editable.ps1
python scripts/cs184-v2-figures.py D:\Draw

python scripts/cs184-package-figures.py

python scripts/cs184-v2-checks.py
npm run build
python scripts/cs184-verify-course.py
