## 需要特别核对的讲解

- 流体 p27、p31：压力修正使用梯度 `∇p`，不是标量拉普拉斯 `∇²p`；保留原页并说明向量维数及散度推导。
- 图像处理 p50：双边滤波需要每个像素自己的权重归一化分母。
- 材质 p24：Schlick 表达式对应 Fresnel 反射率；区分反射、透射和全反射判断。
- 颜色：锥体响应积分解释为光谱与敏感度的内积；区分 PCA 系数和特征值。
- 辐射度方法：明确 Lambertian 情况下 `B = πL` 及形状因子的归一化约定。

## 复现

需要 Python 的 PyMuPDF、Pillow，`D:\Draw` 的 pptdraw 运行环境，以及 Windows PowerPoint（导出原生形状为 PNG）。网站依赖使用仓库 lockfile。

```powershell
npm ci
python scripts/cs184-complete-course.py --pdf-root D:\CS184\CS184_2026 --draw-root D:\Draw --notes --pages --figures
powershell -File scripts/cs184-render-editable.ps1
python scripts/cs184-package-figures.py
python scripts/cs184-numerical-checks.py
npm run build
python scripts/cs184-verify-course.py
```

`--notes`、`--pages`、`--figures` 可以分别使用。已有 PPTX 不会被生成器覆盖，以保留人工编辑；如要从更新后的 JSON 重建，请先备份对应 PPTX，再将待重建文件移至其他目录。`.work/cs184/` 保存本地提取结果、可编辑中间产物和验证报告，不提交到仓库。服务器项目不属于本次笔记构建的依赖。
