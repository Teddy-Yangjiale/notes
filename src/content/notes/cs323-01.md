## 0. 本讲地图

1. **词法分析器的角色**：识别词法单元（tokens）
2. **正则表达式**：用来**描述/指定** token 的模式
3. （下半讲）**有穷自动机**：用来**识别**模式

一句话贯穿全章：**regexp 负责"说清楚要什么"，自动机负责"高效地认出来"。**

## 1. 词法分析器的角色

- 读入源程序的输入字符，按规则**组合成词素（lexeme）**，输出一个**词法单元（token）序列**供语法分析器使用；
- 必要时把词素**加入符号表**。

回顾例子：

```
position = initial + rate * 60
        ↓ Lexical Analyzer
<id,1> <=> <id,2> <+> <id,3> <*> <60>

SYMBOL TABLE: 1 position | 2 initial | 3 rate
```

### 1.1 Token / Pattern / Lexeme 三件套 ★

| 概念 | 定义 |
|---|---|
| **Lexeme（词素）** | 源程序中最低层语法单位的一串字符（具体实例） |
| **Token（词法单元）** | 表示一类词素的**语法范畴**；形式上是 `<token name, attribute value>` |
| **Pattern（模式）** | 描述该 token 的词素**可能具有的形式**（通常用 regexp 写） |

- **Token name**：抽象符号，表示这个 token 的种类；
- **Attribute value**（可选）：指向符号表条目。

课件里的经典表格：

| TOKEN | 模式（非形式描述） | 样例词素 |
|---|---|---|
| `if` | 字符 i, f | `if` |
| `else` | 字符 e, l, s, e | `else` |
| `comparison` | `<` 或 `>` 或 `<=` 或 `>=` 或 `==` 或 `!=` | `<=`, `!=` |
| `id` | 字母开头，后跟字母和数字 | `pi`, `score`, `D2` |
| `number` | 任意数值常量 | `3.14159`, `0`, `6.02e23` |
| `literal` | 被 `"` 括起来的、不含 `"` 的任意内容 | `"core dumped"` |

### 1.2 Token 的属性

- **Token name 影响语法分析决策**；**属性值影响语义分析、代码生成等**。
- 一个 `id` 通常关联：(1) 词素本身，(2) 数据类型，(3) 第一次出现的位置。
- 属性存在**符号表**中。

```
A = B * 2
→ <id, 指向 A 的符号表条目>
  <assign_op>
  <id, 指向 B 的符号表条目>
  <mult_op>
  <number, 整数值 2>
```

### 1.3 词法错误（Lexical Errors）

当**剩余输入的前缀无法匹配任何 token 模式**时发生。

例：`int @3 = 5;` —— `@` 不属于任何模式。

> 注意：`int 3x = 5;` 这种更常见的错误可能在词法阶段就被发现（`3x` 不匹配 number 也不匹配 id 的模式），而 `int x y;` 是语法错误而非词法错误。

## 2. 串和语言（Strings and Languages）★

### 2.1 基本定义

- **字母表（alphabet）Σ**：任意**有限**符号集合。
  - 符号例：字母、数字、标点；字母表例：`{0,1}`、ASCII、Unicode。
- **串（string）**：字母表上符号的**有限序列**。
  - 长度 `|s|`：s 中符号个数；
  - **空串（empty string）ε**：长度为 0 的串。

### 2.2 前缀、后缀、子串、子序列（以 `banana` 为例）★

| 术语 | 定义 | 例子 |
|---|---|---|
| **前缀 prefix** | 从 s **末尾**删去 0 个或多个符号得到的串 | `ban`, `banana`, `ε` |
| **真前缀 proper prefix** | 不是 ε 且不等于 s 本身的前缀 | `ban` |
| **后缀 suffix** | 从 s **开头**删去 0 个或多个符号得到的串 | `nana`, `banana`, `ε` |
| **真后缀 proper suffix** | 不是 ε 且不等于 s 本身的后缀 | `nana` |
| **子串 substring** | 从 s 中删去**某个前缀和某个后缀**得到的串（必须连续） | `banana`, `nan`, `ε` |
| **真子串 proper substring** | 不是 ε 且不等于 s 的子串 | `nan` |
| **子序列 subsequence** | 从 s 中删去 0 个或多个**不必连续**的符号得到的串 | `bnn` |

**关键区分**：子串必须**连续**，子序列**可以跳着取但要保序**。

#### 课后思考题的答案（banana）

- 按**起止下标**计数的非空子串：`n(n+1)/2 = 6×7/2 = 21` 个（含 ε 则 22）；
- 按**内容去重**的非空子串：**15** 个
  （`b, a, n, ba, an, na, ban, ana, nan, bana, anan, nana, banan, anana, banana`）；
- 按下标计数的子序列：`2^6 = 64` 个；
- 按**内容去重**的子序列（含 ε）：**40** 个（不含 ε 为 39）。

> 考试中若题目说 "distinct refers to string content"，一律按**内容去重**计数。

### 2.3 串的运算

- **连接（concatenation）**：`xy` = 把 y 接到 x 后面。
  - x = `I`, y = `♡`, z = `compilers` → `xyz = I♡compilers`
- **幂/指数（exponentiation）**：`s⁰ = ε`，`s¹ = s`，`sⁱ = sⁱ⁻¹s`
  - x = `6` → `x⁰ = ε`，`x¹ = 6`，`x³ = 666`

### 2.4 语言（Language）

**语言 = 某个固定字母表上串的任意可数集合。**

- 只含空串的集合 `{ε}` 是一个语言；
- 空集 `∅` 也是一个语言（注意 `{ε} ≠ ∅`，前者有 1 个元素，后者有 0 个元素）；
- 所有语法正确的英语句子的集合是一个语言；
- 所有语法良构的 C 程序的集合是一个语言。

## 3. 语言上的运算 ★

| 运算 | 定义 |
|---|---|
| **并 Union** of L and M | `L ∪ M = { s \| s ∈ L 或 s ∈ M }` |
| **连接 Concatenation** of L and M | `LM = { st \| s ∈ L 且 t ∈ M }` |
| **Kleene 闭包** of L | `L* = ⋃_{i=0}^{∞} Lⁱ` |
| **正闭包 Positive closure** of L | `L⁺ = ⋃_{i=1}^{∞} Lⁱ` |

- `Lⁿ` = 把 L 连接 n 次；`L⁰ = {ε}`。
- 因此 `L* = L⁺ ∪ {ε}`，`L⁺ = LL*`。
- Kleene 闭包**一定包含 ε**，正闭包只在 `ε ∈ L` 时才含 ε。

### 例子

设 `L = {A,...,Z,a,...,z}`（52 个字母，每个串长度为 1），`D = {0,...,9}`（10 个数字）。

| 表达式 | 含义 |
|---|---|
| `L ∪ D` | 62 个长度为 1 的串 |
| `LD` | 520 个长度为 2 的串（一个字母后跟一个数字） |
| `L⁴` | 所有长度为 4 的字母串（52⁴ 个） |
| `L*` | 所有字母串的集合，**包含 ε** |
| `L(L ∪ D)*` | **以字母开头，后跟任意多个字母或数字** —— 正是标识符（identifier）的模式 |
| `D⁺` | 一个或多个数字组成的串 —— 正是无符号整数的模式 |

> 注意：L 和 D 看起来像"字母表"，但这里把它们定义为**语言**（恰好所有串长度为 1）。

## 4. 正则表达式（Regular Expressions）★★

### 4.1 归纳定义

设 Σ 为字母表。

**基础（BASIS）**：

1. `ε` 是一个 regexp，`L(ε) = {ε}`；
2. 若 `a ∈ Σ`，则 `a` 是一个 regexp，`L(a) = {a}`。

**归纳（INDUCTION）**：设 r、s 是 regexp，分别表示 L(r)、L(s)：

1. `(r)|(s)` 是 regexp，表示 `L(r) ∪ L(s)`；
2. `(r)(s)` 是 regexp，表示 `L(r)L(s)`；
3. `(r)*` 是 regexp，表示 `(L(r))*`；
4. `(r)` 是 regexp，表示 `L(r)`（多加括号不改变语言）。

### 4.2 优先级与结合性（省括号的规则）

- **优先级**：`*`（闭包） > 连接 > `|`（并）
- **结合性**：三个运算符**都是左结合**，即 `a|b|c` 解释为 `(a|b)|c`。

例：`(a) | ((b)*(c))` 可简写为 `a | b*c`。

> 读 regexp 的顺序永远是：先看 `*` 绑到谁身上，再看连接，最后才是 `|`。
> `ab*` = `a(b*)`，不是 `(ab)*`；`a|bc` = `a|(bc)`，不是 `(a|b)c`。

### 4.3 例子（Σ = {a, b}）

| regexp | 语言 |
|---|---|
| `a\|b` | `{a, b}` |
| `(a\|b)(a\|b)` | `{aa, ab, ba, bb}` |
| `a*` | `{ε, a, aa, aaa, ...}` |
| `(a\|b)*` | 由 0 个或多个 a/b 构成的所有串：`{ε,a,b,aa,ab,ba,bb,aaa,...}` |
| `a\|a*b` | 串 `a`，以及由 0 个或多个 a 后跟一个 b 构成的串：`{a, b, ab, aab, aaab, ...}` |

### 4.4 正则语言（Regular Language）

- 能被某个 regexp 定义的语言称为**正则语言**；
- 若 r 和 s 表示同一语言，则称它们**等价**，记作 `r = s`。
- 例：`(a|b)(a|b) = aa|ab|ba|bb` ✔（可用分配律证明）

### 4.5 代数定律 ★（自学材料，但考试会用）

| 定律 | 说明 |
|---|---|
| `r\|s = s\|r` | `\|` 满足交换律 |
| `r\|(s\|t) = (r\|s)\|t` | `\|` 满足结合律 |
| `r(st) = (rs)t` | 连接满足结合律 |
| `r(s\|t) = rs\|rt`；`(s\|t)r = sr\|tr` | 连接对 `\|` 满足分配律 |
| `εr = rε = r` | ε 是连接的单位元 |
| `r* = (r\|ε)*` | 闭包中一定含 ε |
| `r** = r*` | `*` 幂等 |

**记忆技巧**：`|` 像加法 `+`，连接像乘法 `×`，`*` 像幂运算。

> ⚠️ **连接不满足交换律**（`ab ≠ ba`），这是与算术最大的差别，判断两个 regexp 是否等价时最常踩的坑。

## 5. 正则定义（Regular Definitions）

为了书写方便，可以给 regexp 起名字并在后续表达式中复用。

设 Σ 是基本符号的字母表，**正则定义**是形如下面的定义序列：

```
d1 → r1
d2 → r2
   ...
dn → rn
```

其中：

- 每个 `di` 是**不在 Σ 中**、且与其他 d 互不相同的**新符号**；
- 每个 `ri` 是字母表 `Σ ∪ {d1, d2, ..., d_{i-1}}` 上的 regexp。

**第二条的含义**：只能引用**前面已经定义过**的名字（不允许递归定义，否则就超出正则的表达能力了）。

### 例：C 语言标识符

正则定义写法：

```
letter_ → A | B | ... | Z | a | b | ... | z | _
digit   → 0 | 1 | ... | 9
id      → letter_ ( letter_ | digit )*
```

展开成纯 regexp：

```
(A|B|...|Z|a|b|...|z|_) ( (A|B|...|Z|a|b|...|z|_) | (0|1|...|9) )*
```

自测：`_hello` 合法吗？→ **合法**（`_` 属于 letter_）。`3times` 合法吗？→ **不合法**（必须以 letter_ 开头）。

### 例：无符号数（龙书经典）

```
digit  → 0 | 1 | ... | 9
digits → digit digit*
optFrac→ . digits | ε
optExp → ( E ( + | - | ε ) digits ) | ε
number → digits optFrac optExp
```

## 6. 正则表达式的扩展记号

基本算符只有三个：并 `|`、连接、Kleene 闭包 `*`（Kleene 于 1950 年代提出）。常用的记号扩展：

| 扩展 | 含义 | 等价写法 |
|---|---|---|
| `r+` | 一个或多个 r | `r+ = rr*`，`r* = r+ \| ε` |
| `r?` | 零个或一个 r | `r? = r \| ε` |
| `[a1a2...an]` | 字符类 | `= a1 \| a2 \| ... \| an` |
| `[a-e]` | 区间字符类 | `= a \| b \| c \| d \| e` |

**重要结论**：这些扩展**只是记号上的方便，不改变 regexp 的描述能力**（仍然只能描述正则语言）。

> 现实中的 "regex" 引擎有反向引用（backreference）等特性，那些**超出**了正则语言的范围，不要与本课的 regexp 混为一谈。

## 7. 常用套路（写 regexp 的模板）

| 要求（Σ = {0,1}） | regexp |
|---|---|
| 以 0 开头、以 1 结尾 | `0 (0\|1)* 1` |
| 含子串 `010` | `(0\|1)* 010 (0\|1)*` |
| 恰好两个 1 | `0* 1 0* 1 0*` |
| 不含子串 `11` | `(0 \| 10)* (1 \| ε)` |
| 长度为偶数 | `((0\|1)(0\|1))*` |
| 至少含一个 1 | `0*1(0\|1)*` |

**"恰好 k 个某符号"的通法**：把其他符号的闭包夹在 k 个该符号之间，即 `X* a X* a X* ... `。

**"不含某子串"的通法**：改写成"每个 1 后面必须跟 0"这类局部约束，或者先画 DFA 再反推 regexp。
