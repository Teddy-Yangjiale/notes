## 0. 先认识画面：背景和病害并非同一天拍摄

8821 当前由 `crack/viewer3d/site2/serve2.py` 提供页面。它把 0903 的环境底图与 0924 的后摄病害图块放到同一局部坐标系中。所谓“跨天”，不是对两天像素做直接变化检测，而是先解决后一趟观测应该落在前一趟地图哪里的定位问题。

## 2. 先得到一张“每个候选位置有多像”的表

对于一张 0924 照片，算法先按标定把道路区域变成俯视条带。然后围绕定位先验搜索：向右挪多少、沿路挪多少、转多少角度。每个候选都去 0903 底图上取对应区域，计算带通特征的相关分数。

结果不是一个坐标，而是一张分数曲面。把这张曲面保存下来很关键：它保留了第二好、第三好的解释。若第一步就只留下最高峰，后面就没有机会利用时间连续性纠正它。

![8821 历史正射底图](/notes/internship/media/8821-03-ortho.jpg)

*底图内的标线既是可见纹理，也是配准参照。底图的局部拉伸会进入后一趟定位，因此底图并不是外部真值。*

## 3. HMM 的状态是什么？不是抽象的“融合特征”

`t03d_hmm24.py` 把每一步的状态设为 $(b,l)$。$b$ 是相对先验的沿路偏移；$l$ 是相对参考行车轨迹的横向偏移。二者单位都是米。留存实现的网格步长 `DO=DL=0.08`，所以搜索空间由离散候选构成。

用 $z_i=(b_i,l_i)$ 表示第 $i$ 张图的状态，观测得分为 $O_i(z_i)$，转移代价为 $C(z_{i-1},z_i)$。Viterbi 递推是：

$$
V_i(z)=O_i(z)+\max_{z'}\{V_{i-1}(z')-C(z',z)\}.
$$

读法很直接：到达当前候选的最好路径，等于当前图支持它的程度，加上所有前一候选中“历史总分减去跳转代价”的最大值。程序同时保存最大值来自哪个前一状态，最后反向追踪整条路径。

**手算。** 当前图在错误周期的峰比正确周期高 0.4 分，但跳过去的转移罚分是 2。若前面两条路径历史分接近，正确周期仍然胜出。反过来，连续多张强观测都支持另一位置，累积得分可能足以支付跳转代价，这时允许修正旧先验。

## 4. 转移为什么要区分横向和沿路？

横向位置通常缓慢改变，代码让横向转移尺度随站点间距增长。沿路偏移则有两种来源：缓慢的定位误差和突发的旧定位复用。若相邻前摄条带成功量出了运动，沿路状态变化可以用“图像前进量减去先验间距”预测；没有成功量出时，只能给较松的平滑假设。

`maxconv` 实际做的是 max-plus 运算：遍历前后若干格的位移，对候选值减二次惩罚，再逐格保留最大值。它不是普通图像卷积，也不是一个学习出来的神经网络层。

HMM 同时使用前摄和同一时刻后摄的匹配面，但两者来自同一次行车并共享标定。因此“增加了一份证据”不等于“增加一份统计独立的真值”。

## 5. 连续位姿图：把网格初值细化成相机位置

HMM 给的是离散路线解释；`t03f_pose24.py` 再利用连续变量求解。每个节点是平面位置和朝向，相邻视觉运动、图像定位和定位先验成为残差项。一般结构是：

$$
E=\sum_k\rho\left(\left\|W_k\bigl(h_k(\mathbf x)-\mathbf y_k\bigr)\right\|^2\right).
$$

$\mathbf x$ 是待求位姿；$h_k$ 根据位姿预测第 $k$ 个测量；$\mathbf y_k$ 是实际观测；$W_k$ 把米和弧度按各自噪声尺度归一化。这样不能把“误差 0.1 米”和“误差 0.1 弧度”直接加在一起。

对道路而言，一个方向可以强约束，另一个方向可以弱约束。车道线能可靠确定横向位置，却可能无法确定沿路位置。代码中的不同证据等级应理解为信息来源与约束条件，不能直接翻译成“厘米级精度”等级。

## 6. 后摄病害图怎样跟着落位？

车辆位姿确定后，还要加入前后摄的安装相对位置与朝向，得到后摄道路图块的位置。每张图块在自己的局部平面里有固定宽高和像素分辨率；把四角变换到世界坐标，就能作为纹理铺到地图。

![8821 高证据图块的历史展示](/notes/internship/media/8821-04-level3.jpg)

*“高证据”说明满足当时的图像约束条件，不说明这个图块已有独立测量真值。应同时看原始后摄照片、匹配依据和相邻块连续性。*

若同一个裂缝在相邻两张照片中出现，页面可能有两条检测记录。记录数不能直接解释为道路上互不重复的物理病害数量；需要额外的跨图关联与去重。

## 7. 怎样检查结果，而不被漂亮画面说服？

第一，看附近多块图的标线是否在拼接边界保持方向一致；第二，看前后顺序是否与采集顺序相容；第三，检查沿路虚线是否错一个周期；第四，检查无底图覆盖或隧道区域是否明确保留缺失。

![8821 俯视展示](/notes/internship/media/8821-06-top.jpg)

*俯视比驾驶视角更容易暴露纵向缝隙和重复纹理。图像重合能说明内部相容，仍不能单独确认世界坐标绝对准确。*

### 关键片段逐句读

V 是上一层状态得分，pen 是移动若干状态格的惩罚。每次移位后逐格比较，保留更高得分并记录来源；这就是正文Viterbi递推的局部实现。

原文件定位：[t03d_hmm24.py 第 32 行](/notes/internship/code/8821-t03d_hmm24.py.html#L32)。以下为真实节选，依赖所在文件上下文，不是独立可运行程序。

```python
def maxconv(V, sig, step, axis):
    """max-plus 卷积: out[x] = max_x' V[x'] - (x-x')^2 / (2 sig^2), 返回 out 与 argmax 的位移 (格)"""
    r = max(1, int(np.ceil(3.0 * sig / step)))
    best = np.full(V.shape, -np.inf, np.float32); arg = np.zeros(V.shape, np.int32)
    for d in range(-r, r + 1):
        pen = -0.5 * (d * step / sig) ** 2
        sh = np.full(V.shape, -np.inf, np.float32)
        if axis == 0:
            if d > 0: sh[d:] = V[:-d]
            elif d < 0: sh[:d] = V[-d:]
            else: sh[:] = V
        else:
            if d > 0: sh[:, d:] = V[:, :-d]
            elif d < 0: sh[:, :d] = V[:, -d:]
            else: sh[:] = V
        sh += pen
        m = sh > best; best[m] = sh[m]; arg[m] = d          # x' = x - d
    return best, arg

if __name__ == "__main__":
    t0 = time.time()
```
