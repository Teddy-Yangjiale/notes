  71     """Rasterize a set of 3D Gaussians (N) to a batch of image planes (C).
  72 
  73     This function provides a handful features for 3D Gaussian rasterization, which
  74     we detail in the following notes. A complete profiling of the these features
  75     can be found in the :ref:`profiling` page.
  76 
  77     .. note::
  78         **Multi-GPU Distributed Rasterization**: This function can be used in a multi-GPU
  79         distributed scenario by setting `distributed` to True. When `distributed` is True,
  80         a subset of total Gaussians could be passed into this function in each rank, and
  81         the function will collaboratively render a set of images using Gaussians from all ranks. Note
  82         to achieve balanced computation, it is recommended (not enforced) to have similar number of
  83         Gaussians in each rank. But we do enforce that the number of cameras to be rendered
  84         in each rank is the same. The function will return the rendered images
  85         corresponds to the input cameras in each rank, and allows for gradients to flow back to the
  86         Gaussians living in other ranks. For the details, please refer to the paper
  87         `On Scaling Up 3D Gaussian Splatting Training <https://arxiv.org/abs/2406.18533>`_.
  88 
  89     .. note::
  90         **Batch Rasterization**: This function allows for rasterizing a set of 3D Gaussians
  91         to a batch of images in one go, by simplly providing the batched `viewmats` and `Ks`.
  92 
  93     .. note::
  94         **Support N-D Features**: If `sh_degree` is None,
  95         the `colors` is expected to be with shape [..., N, D] or [..., C, N, D], in which D is the channel of
  96         the features to be rendered. The computation is slow when D > 32 at the moment.
  97         If `sh_degree` is set, the `colors` is expected to be the SH coefficients with
  98         shape [..., N, K, 3] or [..., C, N, K, 3], where K is the number of SH bases. In this case, it is expected
  99         that :math:`(\\textit{sh_degree} + 1) ^ 2 \\leq K`, where `sh_degree` controls the
 100         activated bases in the SH coefficients.
 101 
 102     .. note::
 103         **Depth Rendering**: This function supports colors or/and depths via `render_mode`.
 104         The supported modes are "RGB", "D", "ED", "RGB+D", and "RGB+ED". "RGB" renders the
 105         colored image that respects the `colors` argument. "D" renders the accumulated z-depth
 106         :math:`\\sum_i w_i z_i`. "ED" renders the expected z-depth
 107         :math:`\\frac{\\sum_i w_i z_i}{\\sum_i w_i}`. "RGB+D" and "RGB+ED" render both
 108         the colored image and the depth, in which the depth is the last channel of the output.
 109 
 110     .. note::
 111         **Memory-Speed Trade-off**: The `packed` argument provides a trade-off between
 112         memory footprint and runtime. If `packed` is True, the intermediate results are
 113         packed into sparse tensors, which is more memory efficient but might be slightly
 114         slower. This is especially helpful when the scene is large and each camera sees only
 115         a small portion of the scene. If `packed` is False, the intermediate results are
 116         with shape [..., C, N, ...], which is faster but might consume more memory.
 117 
 118     .. note::
 119         **Sparse Gradients**: If `sparse_grad` is True, the gradients for {means, quats, scales}
 120         will be stored in a `COO sparse layout <https://pytorch.org/docs/stable/generated/torch.sparse_coo_tensor.html>`_.
 121         This can be helpful for saving memory
 122         for training when the scene is large and each iteration only activates a small portion
 123         of the Gaussians. Usually a sparse optimizer is required to work with sparse gradients,
 124         such as `torch.optim.SparseAdam <https://pytorch.org/docs/stable/generated/torch.optim.SparseAdam.html#sparseadam>`_.
 125         This argument is only effective when `packed` is True.
 126 
 127     .. note::
 128         **Speed-up for Large Scenes**: The `radius_clip` argument is extremely helpful for
 129         speeding up large scale scenes or scenes with large depth of fields. Gaussians with
 130         2D radius smaller or equal than this value (in pixel unit) will be skipped during rasterization.
 131         This will skip all the far-away Gaussians that are too small to be seen in the image.
 132         But be warned that if there are close-up Gaussians that are also below this threshold, they will
 133         also get skipped (which is rarely happened in practice). This is by default disabled by setting
 134         `radius_clip` to 0.0.
 135 
 136     .. note::
 137         **Antialiased Rendering**: If `rasterize_mode` is "antialiased", the function will
 138         apply a view-dependent compensation factor
 139         :math:`\\rho=\\sqrt{\\frac{Det(\\Sigma)}{Det(\\Sigma+ \\epsilon I)}}` to Gaussian
 140         opacities, where :math:`\\Sigma` is the projected 2D covariance matrix and :math:`\\epsilon`
 141         is the `eps2d`. This will make the rendered image more antialiased, as proposed in
 142         the paper `Mip-Splatting: Alias-free 3D Gaussian Splatting <https://arxiv.org/pdf/2311.16493>`_.
 143 
 144     .. note::
 145         **AbsGrad**: If `absgrad` is True, the absolute gradients of the projected
 146         2D means will be computed during the backward pass, which could be accessed by
 147         `meta["means2d"].absgrad`. This is an implementation of the paper
 148         `AbsGS: Recovering Fine Details for 3D Gaussian Splatting <https://arxiv.org/abs/2404.10484>`_,
 149         which is shown to be more effective for splitting Gaussians during training.
 150 
 151     .. note::
 152         **Camera Distortion and Rolling Shutter**: The function supports rendering with opencv
 153         distortion formula for pinhole and fisheye cameras (`radial_coeffs`, `tangential_coeffs`, `thin_prism_coeffs`).
 154         It also supports rolling shutter rendering with the `rolling_shutter` argument. We take
 155         reference from the paper `3DGUT: Enabling Distorted Cameras and Secondary Rays in Gaussian Splatting
 156         <https://arxiv.org/abs/2412.12507>`_.
 157 
 158     .. warning::
 159         This function is currently not differentiable w.r.t. the camera intrinsics `Ks`.

 502                 # Turn [..., N, K, 3] into [nnz, 3]
 503                 shs = colors.view(B, N, -1, 3)[batch_ids, gaussian_ids]  # [nnz, K, 3]
 504             else:
 505                 # Turn [..., C, N, K, 3] into [nnz, 3]
 506                 shs = colors.view(B, C, N, -1, 3)[
 507                     batch_ids, camera_ids, gaussian_ids
 508                 ]  # [nnz, K, 3]
 509             colors = spherical_harmonics(sh_degree, dirs, shs, masks=masks)  # [nnz, 3]
 510         else:
 511             dirs = means[..., None, :, :] - campos[..., None, :]  # [..., C, N, 3]

 515                 shs = torch.broadcast_to(
 516                     colors[..., None, :, :, :], batch_dims + (C, N, -1, 3)
 517                 )
 518             else:
 519                 # colors is already [..., C, N, K, 3]
 520                 shs = colors
 521             colors = spherical_harmonics(
 522                 sh_degree, dirs, shs, masks=masks
 523             )  # [..., C, N, 3]
 524         # make it apple-to-apple with Inria's CUDA Backend.
 525         colors = torch.clamp_min(colors + 0.5, 0.0)

 528     # on which cameras they are visible to, which we already figured out in the projection
 529     # stage.
 530     if distributed:
 531         if packed:
 532             # count how many elements need to be sent to each rank
 533             cnts = torch.bincount(camera_ids, minlength=C)  # all cameras
 534             cnts = cnts.split(C_world, dim=0)
 535             cnts = [cuts.sum() for cuts in cnts]
 536 
 537             # all to all communication across all ranks. After this step, each rank
 538             # would have all the necessary GSs to render its own images.
 539             collected_splits = all_to_all_int32(world_size, cnts, device=device)
 540             (radii,) = all_to_all_tensor_list(
 541                 world_size, [radii], cnts, output_splits=collected_splits
 542             )
 543             (means2d, depths, conics, opacities, colors) = all_to_all_tensor_list(
 544                 world_size,
 545                 [means2d, depths, conics, opacities, colors],
 546                 cnts,
 547                 output_splits=collected_splits,
 548             )
 549 
 550             # before sending the data, we should turn the camera_ids from global to local.
 551             # i.e. the camera_ids produced by the projection stage are over all cameras world-wide,
 552             # so we need to turn them into camera_ids that are local to each rank.
 553             offsets = torch.tensor(
 554                 [0] + C_world[:-1], device=camera_ids.device, dtype=camera_ids.dtype
 555             )
 556             offsets = torch.cumsum(offsets, dim=0)
 557             offsets = offsets.repeat_interleave(torch.stack(cnts))
 558             camera_ids = camera_ids - offsets
 559 
 560             # and turn gaussian ids from local to global.
 561             offsets = torch.tensor(
 562                 [0] + N_world[:-1],
 563                 device=gaussian_ids.device,
 564                 dtype=gaussian_ids.dtype,
 565             )
 566             offsets = torch.cumsum(offsets, dim=0)

 571             (camera_ids, gaussian_ids) = all_to_all_tensor_list(
 572                 world_size,
 573                 [camera_ids, gaussian_ids],
 574                 cnts,
 575                 output_splits=collected_splits,
 576             )
 577 
 578             # Silently change C from global #Cameras to local #Cameras.
 579             C = C_world[world_rank]
 580 
 581         else:
 582             # Silently change C from global #Cameras to local #Cameras.
 583             C = C_world[world_rank]
 584 
 585             # all to all communication across all ranks. After this step, each rank
 586             # would have all the necessary GSs to render its own images.
 587             (radii,) = all_to_all_tensor_list(
 588                 world_size,
 589                 [radii.flatten(0, 1)],
 590                 splits=[C_i * N for C_i in C_world],
 591                 output_splits=[C * N_i for N_i in N_world],
 592             )
 593             radii = reshape_view(C, radii, N_world)
 594 
 595             (means2d, depths, conics, opacities, colors) = all_to_all_tensor_list(
 596                 world_size,
 597                 [
 598                     means2d.flatten(0, 1),
 599                     depths.flatten(0, 1),
 600                     conics.flatten(0, 1),
 601                     opacities.flatten(0, 1),
 602                     colors.flatten(0, 1),
 603                 ],
 604                 splits=[C_i * N for C_i in C_world],
 605                 output_splits=[C * N_i for N_i in N_world],
 606             )
 607             means2d = reshape_view(C, means2d, N_world)
 608             depths = reshape_view(C, depths, N_world)
 609             conics = reshape_view(C, conics, N_world)
 610             opacities = reshape_view(C, opacities, N_world)
 611             colors = reshape_view(C, colors, N_world)
 612 
 613     # Rasterize to pixels
 614     if render_mode in ["RGB+D", "RGB+ED"]:
 615         colors = torch.cat((colors, depths[..., None]), dim=-1)
 616         if backgrounds is not None:
 617             backgrounds = torch.cat(
 618                 [
 619                     backgrounds,
 620                     torch.zeros(batch_dims + (C, 1), device=backgrounds.device),
 621                 ],
 622                 dim=-1,
 623             )
 624     elif render_mode in ["D", "ED"]:
 625         colors = depths[..., None]
 626         if backgrounds is not None:
 627             backgrounds = torch.zeros(batch_dims + (C, 1), device=backgrounds.device)
 628     else:  # RGB
 629         pass
 630 
 631     # Identify intersecting tiles
 632     tile_width = math.ceil(width / float(tile_size))
 633     tile_height = math.ceil(height / float(tile_size))
 634     tiles_per_gauss, isect_ids, flatten_ids = isect_tiles(
 635         means2d,
 636         radii,
 637         depths,
 638         tile_size,
 639         tile_width,
 640         tile_height,
 641         segmented=segmented,
 642         packed=packed,
 643         n_images=I,
 644         image_ids=image_ids,
 645         gaussian_ids=gaussian_ids,
 646     )
 647     # print("rank", world_rank, "Before isect_offset_encode")
 648     isect_offsets = isect_offset_encode(isect_ids, I, tile_width, tile_height)
 649     isect_offsets = isect_offsets.reshape(batch_dims + (C, tile_height, tile_width))
 650 
 651     meta.update(
 652         {
 653             "tile_width": tile_width,
 654             "tile_height": tile_height,
 655             "tiles_per_gauss": tiles_per_gauss,
 656             "isect_ids": isect_ids,
 657             "flatten_ids": flatten_ids,
 658             "isect_offsets": isect_offsets,
 659             "width": width,
 660             "height": height,
 661             "tile_size": tile_size,
 662             "n_batches": B,
 663             "n_cameras": C,
 664         }
 665     )
 666

 671         render_colors, render_alphas = [], []
 672         for i in range(n_chunks):

 674             backgrounds_chunk = (
 675                 backgrounds[..., i * channel_chunk : (i + 1) * channel_chunk]
 676                 if backgrounds is not None
 677                 else None
 678             )
 679             if with_eval3d:
 680                 render_colors_, render_alphas_ = rasterize_to_pixels_eval3d(
 681                     means,
 682                     quats,
 683                     scales,
 684                     colors_chunk,
 685                     opacities,
 686                     viewmats,

 688                     width,
 689                     height,

 694                     camera_model=camera_model,
 695                     radial_coeffs=radial_coeffs,
 696                     tangential_coeffs=tangential_coeffs,
 697                     thin_prism_coeffs=thin_prism_coeffs,
 698                     ftheta_coeffs=ftheta_coeffs,

 713                     backgrounds=backgrounds_chunk,

 719         render_colors = torch.cat(render_colors, dim=-1)
 720         render_alphas = render_alphas[0]  # discard the rest
 721     else:
 722         if with_eval3d:
 723             render_colors, render_alphas = rasterize_to_pixels_eval3d(
 724                 means,
 725                 quats,

 773 def _rasterization(
 774     means: Tensor,  # [..., N, 3]
 775     quats: Tensor,  # [..., N, 4]
 776     scales: Tensor,  # [..., N, 3]
 777     opacities: Tensor,  # [..., N]
 778     colors: Tensor,  # [..., (C,) N, D] or [..., (C,) N, K, 3]
 779     viewmats: Tensor,  # [..., C, 4, 4]
 780     Ks: Tensor,  # [..., C, 3, 3]
 781     width: int,
 782     height: int,
 783     near_plane: float = 0.01,
 784     far_plane: float = 1e10,
 785     eps2d: float = 0.3,
 786     sh_degree: Optional[int] = None,
 787     tile_size: int = 16,
 788     backgrounds: Optional[Tensor] = None,
 789     render_mode: Literal["RGB", "D", "ED", "RGB+D", "RGB+ED"] = "RGB",
 790     rasterize_mode: Literal["classic", "antialiased"] = "classic",
 791     channel_chunk: int = 32,
 792     batch_per_iter: int = 100,
 793 ) -> Tuple[Tensor, Tensor, Dict]:
 794     """A version of rasterization() that utilies on PyTorch's autograd.
 795 
 796     .. note::
 797         This function still relies on gsplat's CUDA backend for some computation, but the
 798         entire differentiable graph is on of PyTorch (and nerfacc) so could use Pytorch's
 799         autograd for backpropagation.
 800 
 801     .. note::
 802         This function relies on installing latest nerfacc, via:
 803         pip install git+https://github.com/nerfstudio-project/nerfacc
 804 
 805     .. note::
 806         Compared to rasterization(), this function does not support some arguments such as
 807         `packed`, `sparse_grad` and `absgrad`.
 808     """
 809     from gsplat.cuda._torch_impl import (
 810         _fully_fused_projection,
 811         _quat_scale_to_covar_preci,
 812         _rasterize_to_pixels,
 813     )
 814 
 815     batch_dims = means.shape[:-2]
 816     num_batch_dims = len(batch_dims)
 817     B = math.prod(batch_dims)
 818     N = means.shape[-2]
 819     C = viewmats.shape[-3]
 820     I = B * C
 821     device = means.device
 822     assert means.shape == batch_dims + (N, 3), means.shape
 823     assert quats.shape == batch_dims + (N, 4), quats.shape
 824     assert scales.shape == batch_dims + (N, 3), scales.shape
 825     assert opacities.shape == batch_dims + (N,), opacities.shape
 826     assert viewmats.shape == batch_dims + (C, 4, 4), viewmats.shape
 827     assert Ks.shape == batch_dims + (C, 3, 3), Ks.shape
 828     assert render_mode in ["RGB", "D", "ED", "RGB+D", "RGB+ED"], render_mode
 829 
 830     if sh_degree is None:
 831         # treat colors as post-activation values, should be in shape [..., N, D] or [..., C, N, D]
 832         assert (
 833             colors.dim() == num_batch_dims + 2
 834             and colors.shape[:-1] == batch_dims + (N,)
 835         ) or (
 836             colors.dim() == num_batch_dims + 3
 837             and colors.shape[:-1] == batch_dims + (C, N)
 838         ), colors.shape
 839     else:
 840         # treat colors as SH coefficients, should be in shape [..., N, K, 3] or [..., C, N, K, 3]
 841         # Allowing for activating partial SH bands
 842         assert (
 843             colors.dim() == num_batch_dims + 3
 844             and colors.shape[:-2] == batch_dims + (N,)
 845             and colors.shape[-1] == 3
 846         ) or (
 847             colors.dim() == num_batch_dims + 4
 848             and colors.shape[:-2] == batch_dims + (C, N)
 849             and colors.shape[-1] == 3
 850         ), colors.shape
 851         assert (sh_degree + 1) ** 2 <= colors.shape[-2], colors.shape
 852 
 853     # Project Gaussians to 2D.
 854     # The results are with shape [..., C, N, ...]. Only the elements with radii > 0 are valid.
 855     covars, _ = _quat_scale_to_covar_preci(quats, scales, True, False, triu=False)
 856     radii, means2d, depths, conics, compensations = _fully_fused_projection(
 857         means,
 858         covars,
 859         viewmats,
 860         Ks,
 861         width,
 862         height,
 863         eps2d=eps2d,
 864         near_plane=near_plane,
 865         far_plane=far_plane,
 866         calc_compensations=(rasterize_mode == "antialiased"),
 867     )
 868     opacities = torch.broadcast_to(
 869         opacities[..., None, :], batch_dims + (C, N)
 870     )  # [..., C, N]
 871     batch_ids, camera_ids, gaussian_ids = None, None, None
 872     image_ids = None
 873 
 874     if compensations is not None:
 875         opacities = opacities * compensations
 876 
 877     # Identify intersecting tiles
 878     tile_width = math.ceil(width / float(tile_size))
 879     tile_height = math.ceil(height / float(tile_size))
 880     tiles_per_gauss, isect_ids, flatten_ids = isect_tiles(
 881         means2d,
 882         radii,
 883         depths,
 884         tile_size,
 885         tile_width,
 886         tile_height,
 887         packed=False,
 888         n_images=I,
 889         image_ids=image_ids,
 890         gaussian_ids=gaussian_ids,
 891     )
 892     isect_offsets = isect_offset_encode(isect_ids, I, tile_width, tile_height)
 893     isect_offsets = isect_offsets.reshape(batch_dims + (C, tile_height, tile_width))
 894 
 895     # Turn colors into [..., C, N, D] or [..., nnz, D] to pass into rasterize_to_pixels()
 896     if sh_degree is None:
 897         # Colors are post-activation values, with shape [..., N, D] or [..., C, N, D]
 898         if colors.dim() == num_batch_dims + 2:
 899             # Turn [..., N, D] into [..., C, N, D]
 900             colors = torch.broadcast_to(
 901                 colors[..., None, :, :], batch_dims + (C, N, -1)
 902             )
 903         else:
 904             # colors is already [..., C, N, D]
 905             pass
 906     else:
 907         # Colors are SH coefficients, with shape [..., N, K, 3] or [..., C, N, K, 3]
 908         camtoworlds = torch.inverse(viewmats)  # [..., C, 4, 4]
 909         dirs = means[..., None, :, :] - camtoworlds[..., None, :3, 3]  # [..., C, N, 3]
 910         masks = (radii > 0).all(dim=-1)  # [..., C, N]
 911         if colors.dim() == num_batch_dims + 3:
 912             # Turn [..., N, K, 3] into [..., C, N, K, 3]
 913             shs = torch.broadcast_to(
 914                 colors[..., None, :, :, :], batch_dims + (C, N, -1, 3)
 915             )  # [..., C, N, K, 3]
 916         else:
 917             # colors is already [..., C, N, K, 3]
 918             shs = colors
 919         colors = spherical_harmonics(
 920             sh_degree, dirs, shs, masks=masks
 921         )  # [..., C, N, 3]
 922         # make it apple-to-apple with Inria's CUDA Backend.
 923         colors = torch.clamp_min(colors + 0.5, 0.0)
 924 
 925     # Rasterize to pixels
 926     if render_mode in ["RGB+D", "RGB+ED"]:
 927         colors = torch.cat((colors, depths[..., None]), dim=-1)
 928         if backgrounds is not None:
 929             backgrounds = torch.cat(
 930                 [
 931                     backgrounds,
 932                     torch.zeros(batch_dims + (C, 1), device=backgrounds.device),
 933                 ],
 934                 dim=-1,
 935             )
 936     elif render_mode in ["D", "ED"]:
 937         colors = depths[..., None]
 938         if backgrounds is not None:
 939             backgrounds = torch.zeros(batch_dims + (C, 1), device=backgrounds.device)
 940     else:  # RGB
 941         pass
 942     if colors.shape[-1] > channel_chunk:
 943         # slice into chunks
 944         n_chunks = (colors.shape[-1] + channel_chunk - 1) // channel_chunk
 945         render_colors, render_alphas = [], []
 946         for i in range(n_chunks):
 947             colors_chunk = colors[..., i * channel_chunk : (i + 1) * channel_chunk]
 948             backgrounds_chunk = (
 949                 backgrounds[..., i * channel_chunk : (i + 1) * channel_chunk]
 950                 if backgrounds is not None
 951                 else None
 952             )
 953             render_colors_, render_alphas_ = _rasterize_to_pixels(
 954                 means2d,
 955                 conics,
 956                 colors_chunk,
 957                 opacities,
 958                 width,
 959                 height,
 960                 tile_size,
 961                 isect_offsets,
 962                 flatten_ids,
 963                 backgrounds=backgrounds_chunk,
 964                 batch_per_iter=batch_per_iter,
 965             )
 966             render_colors.append(render_colors_)
 967             render_alphas.append(render_alphas_)
 968         render_colors = torch.cat(render_colors, dim=-1)
 969         render_alphas = render_alphas[0]  # discard the rest
 970     else:
 971         render_colors, render_alphas = _rasterize_to_pixels(
 972             means2d,
 973             conics,
 974             colors,
 975             opacities,
 976             width,
 977             height,
 978             tile_size,
 979             isect_offsets,
 980             flatten_ids,
 981             backgrounds=backgrounds,
 982             batch_per_iter=batch_per_iter,
 983         )
 984     if render_mode in ["ED", "RGB+ED"]:
 985         # normalize the accumulated depth to get the expected depth
 986         render_colors = torch.cat(
 987             [
 988                 render_colors[..., :-1],
 989                 render_colors[..., -1:] / render_alphas.clamp(min=1e-10),
 990             ],
 991             dim=-1,
 992         )
 993 
 994     meta = {
 995         "batch_ids": batch_ids,
 996         "camera_ids": camera_ids,
 997         "gaussian_ids": gaussian_ids,
 998         "radii": radii,
 999         "means2d": means2d,
1000         "depths": depths,
1001         "conics": conics,
1002         "opacities": opacities,
1003         "tile_width": tile_width,
1004         "tile_height": tile_height,
1005         "tiles_per_gauss": tiles_per_gauss,
1006         "isect_ids": isect_ids,
1007         "flatten_ids": flatten_ids,
1008         "isect_offsets": isect_offsets,
1009         "width": width,
1010         "height": height,
1011         "tile_size": tile_size,
1012         "n_batches": B,
1013         "n_cameras": C,
1014     }
1015     return render_colors, render_alphas, meta

1639     height: int,
1640     near_plane: float = 0.01,
1641     far_plane: float = 100.0,
1642     eps2d: float = 0.3,

1644     backgrounds: Optional[Tensor] = None,
1645     depth_ratio: int = 0,
1646     **kwargs,
1647 ) -> Tuple[Tuple, Dict]:

1649 
1650     Install the 2DGS rasterization backend from
1651         https://github.com/hbb1/diff-surfel-rasterization
1652 
1653     Credit to Jeffrey Hu https://github.com/jefequien
1654 
1655     """
1656     from diff_surfel_rasterization import (
1657         GaussianRasterizationSettings,
1658         GaussianRasterizer,
1659     )
1660 
1661     assert eps2d == 0.3, "This is hard-coded in CUDA to be 0.3"
1662     C = len(viewmats)
1663     device = means.device
1664     channels = colors.shape[-1]
1665 
1666     # rasterization from inria does not do normalization internally
1667     quats = F.normalize(quats, dim=-1)  # [N, 4]
1668     scales = scales[:, :2]  # [N, 2]
1669 
1670     render_colors = []
1671     for cid in range(C):
1672         FoVx = 2 * math.atan(width / (2 * Ks[cid, 0, 0].item()))
1673         FoVy = 2 * math.atan(height / (2 * Ks[cid, 1, 1].item()))

1675         tanfovy = math.tan(FoVy * 0.5)
1676

1678         projection_matrix = get_projection_matrix(
1679             znear=near_plane, zfar=far_plane, fovX=FoVx, fovY=FoVy, device=device
1680         ).transpose(0, 1)
1681         full_proj_transform = (
1682             world_view_transform.unsqueeze(0).bmm(projection_matrix.unsqueeze(0))
1683         ).squeeze(0)
1684         camera_center = world_view_transform.inverse()[3, :3]
1685 
1686         background = (
1687             backgrounds[cid]
1688             if backgrounds is not None
1689             else torch.zeros(3, device=device)
1690         )
1691 
1692         raster_settings = GaussianRasterizationSettings(
1693             image_height=height,
1694             image_width=width,
1695             tanfovx=tanfovx,
1696             tanfovy=tanfovy,
1697             bg=background,
1698             scale_modifier=1.0,
1699             viewmatrix=world_view_transform,
1700             projmatrix=full_proj_transform,
1701             sh_degree=0 if sh_degree is None else sh_degree,
1702             campos=camera_center,
1703             prefiltered=False,
1704             debug=False,
1705         )
1706 
1707         rasterizer = GaussianRasterizer(raster_settings=raster_settings)
1708 
1709         means2D = torch.zeros_like(means, requires_grad=True, device=device)
1710 
1711         render_colors_ = []
1712         for i in range(0, channels, 3):
1713             _colors = colors[..., i : i + 3]
1714             if _colors.shape[-1] < 3:
1715                 pad = torch.zeros(
1716                     _colors.shape[0], 3 - _colors.shape[-1], device=device
1717                 )
1718                 _colors = torch.cat([_colors, pad], dim=-1)
1719             _render_colors_, radii, allmap = rasterizer(
1720                 means3D=means,
1721                 means2D=means2D,
1722                 shs=_colors if colors.dim() == 3 else None,
1723                 colors_precomp=_colors if colors.dim() == 2 else None,
1724                 opacities=opacities[:, None],
1725                 scales=scales,
1726                 rotations=quats,
1727                 cov3D_precomp=None,
1728             )
1729             if _colors.shape[-1] < 3:
1730                 _render_colors_ = _render_colors_[:, :, : _colors.shape[-1]]
1731             render_colors_.append(_render_colors_)
1732         render_colors_ = torch.cat(render_colors_, dim=-1)
1733 
1734         render_colors_ = render_colors_.permute(1, 2, 0)  # [H, W, 3]
1735         render_colors.append(render_colors_)
1736     render_colors = torch.stack(render_colors, dim=0)
1737

1739     allmap = allmap.permute(1, 2, 0).unsqueeze(0)  # [1, H, W, C]
1740     render_depth_expected = allmap[..., 0:1]
1741     render_alphas = allmap[..., 1:2]
1742     render_normal = allmap[..., 2:5]
1743     render_depth_median = allmap[..., 5:6]

1745 
1746     render_normal = render_normal @ (world_view_transform[:3, :3].T)
1747     render_depth_expected = render_depth_expected / render_alphas
1748     render_depth_expected = torch.nan_to_num(render_depth_expected, 0, 0)
1749     render_depth_median = torch.nan_to_num(render_depth_median, 0, 0)
1750

1752     # for bounded scene, use median depth, i.e., depth_ratio = 1;
1753     # for unbounded scene, use expected depth, i.e., depth_ratio = 0, to reduce disk aliasing.
1754     render_depth = (
1755         render_depth_expected * (1 - depth_ratio) + (depth_ratio) * render_depth_median
1756     )
1757 
1758     normals_surf = depth_to_normal(render_depth, torch.linalg.inv(viewmats), Ks)
1759     normals_surf = normals_surf * (render_alphas).detach()
1760 
1761     render_colors = torch.cat([render_colors, render_depth], dim=-1)
1762 
1763     meta = {
1764         "normals_rend": render_normal,
1765         "normals_surf": normals_surf,
1766         "render_distloss": render_dist,
1767         "means2d": means2D,
1768         "width": width,
1769         "height": height,
1770         "radii": radii.unsqueeze(0),
1771         "n_cameras": C,
1772         "gaussian_ids": None,
1773     }
1774     return (render_colors, render_alphas), meta
