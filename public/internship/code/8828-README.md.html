  73 ## 查明的问题与处理
  74 
  75 1. **DVR 录像的路面纹理弱，条带里程计跟不住**。`probe_vo.py` 同一套 `vo_images` 分步对比：路面占比 0.57 vs 0.53、带通纹理强度 7.8 vs 5.9 差两成，但角点数 408 vs 71 差 5.7 倍，LK 跟住数和 RANSAC 内点随之不够。
  76    放宽角点阈值（抽样成功率 50% → 67%）+ 粗配备用边后，相邻对连通 34% → 61%；剩下的差距是数据本身（压缩画质），没有再往下抠。
  77 2. **里程计位移比定位短 4.4%，原因是前摄俯仰标定偏小 0.3°（已查明、已改）。** 线索：比值随加速度变（加速 1.01、匀速 0.95、减速 0.90），改定位超前量 0~1.1 s 都不变，排除时间偏移；
  78    定位折线与 0903 位姿图长度只差 ±1.5%、`1012.csv` 位移/车速自洽 1.004，排除定位；卷帘快门最多解释 1.3%。俯仰错会让条带沿路尺度随距离线性变，正是 0903 当年 t01c 的两把尺子量的东西：
  79    `probe_pitch.py` 在 200 对匀速相邻帧上按候选俯仰重渲染条带跑同一套里程计——4.61 时 位移/弧长 0.937、远近残差斜率 −0.0034/m；4.93 时 1.00 / 0；5.25 时 1.042 / +0.0030。两把尺子都指向 **4.93**，高度 1.497 不用动（该处比值已是 1）。
  80    加速/减速两组的差是车身俯仰（加速抬头、刹车点头），静态标定消不掉。`t03c_calmatch12` 对 0903 正射图的匹配分数对俯仰只差 1~3%，定不住俯仰，所以当时的 4.61 是错的；8826 里那份 1012 病害层仍用 4.61（没动）。
  81    另：黑匣子的 speed 字段不可靠（同一时刻与 csv 车速之比中位 0.995 但 p10 只有 0.54），尺度系数改按定位弧长算。
  82 3. **平台定位的 0.56 s 超前也作用于底图**。第一次配病害层时先验相对底图“向后 −5.65 m”（IQR −6.6~−3.2，搜索窗 ±7 m 快撑满），说明底图整体超前；`t01e_1012` 把 csv 时刻加 0.56 s 后，HMM 相对先验只剩 −1.24 m（IQR −1.56~−0.76）。
  83 4. **ABot demo 默认 504×280**（`InferenceConfig` 默认；0903 那次是 420×756）：`from_pretrained(..., height=420, width=756)` 即可，t04 里点图像素到原图像素的换算随之参数化。
